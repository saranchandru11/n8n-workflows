This is a hosted rebuild of my IT Support Ticket Triage System — the same n8n + Claude API automation I use to classify tickets by priority, category and sentiment, and draft a first reply, in seconds instead of minutes. Every reply is grounded in a retrieved knowledge base: the ticket is matched against 10 support articles, and only the closest ones are given to the model. You'll see exactly which article each answer came from.
